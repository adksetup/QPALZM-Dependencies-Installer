# QPALZM Dependencies Installer
QPALZM Toolkit通用依赖安装器，可在MacOS / Linux / Windows里运行次脚本以安装所有QPALZM Toolkit的依赖。
## 包含的包（Package）
- CustomTkinter
- TermColor
## 用法
MacOS / Linux:
```bash
chmod +x install_dependencies.sh
./install_dependencies.sh
```
Windows: 双击BAT文件
## Release Assets 附件下载
- `install_dependencies.sh` - MacOS / Linux 依赖安装器
- `InstallDependencies.bat` - Windows 依赖安装器
